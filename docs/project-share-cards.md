# بطاقات مشاركة مشاريع Alpha Line

تُنشأ بطاقة مشاركة ثابتة لكل مشروع تلقائيًا من بياناته في `src/content/projects/` عند تنفيذ `pnpm build`. لا تحتاج إلى إعداد صورة Open Graph منفصلة لكل مشروع في الوضع الحالي.

| المصدر | المسار الناتج | المحتوى الظاهر |
|---|---|---|
| `steins-gate.json` | `/og/projects/steins-gate/` | غلاف اللعبة، الاسم العربي والإنجليزي، حالة التعريب، السلسلة، المنصات، رقم المسار والإصدار الحالي. |
| أي ملف مشروع جديد | `/og/projects/<slug>/` | نفس القالب مع بيانات المشروع الجديد تلقائيًا. |

> صفحة المشروع نفسها تشير تلقائيًا إلى بطاقة المسار المقابلة عبر وسم `og:image`. وعند تعيين الدومين النهائي في `astro.config.mjs` ستتحول الروابط المطلقة في بيانات المشاركة إليه تلقائيًا.

## تخصيص اختياري

يستخدم القالب `coverImage` بصفته صورة اللعبة. إذا احتاج مشروع معين إلى صورة مخصصة للمشاركة، أضف الحقل الاختياري `ogImage` في ملف JSON الخاص به وضع فيه رابط الصورة. سيبقى تصميم البطاقة ومعلوماتها كما هي.
