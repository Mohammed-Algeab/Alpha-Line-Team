# Alpha Line — موجز مراجعة وتطوير الخطة باستخدام الذكاء الاصطناعي

## ما هذا المشروع؟

**Alpha Line / ألفا لاين** فريق عربي لتعريب الألعاب. يبدأ العمل حول Steins;Gate وسلسلة Science Adventure، ثم يتوسع فقط إلى مشاريع واقعية يمكن تنفيذها. الموقع مبني بـ **Astro** كموقع Static حقيقي؛ يولّد صفحات HTML مستقلة للمشاريع والمقالات والتصنيفات لتحسين SEO. لا نريد React SPA أو قاعدة بيانات أو لوحة إدارة في المرحلة الحالية.

## قيود غير قابلة للتفاوض

1. الموقع **Static** ويجب أن يبقى مولّد صفحات HTML مستقلة وصديقًا لمحركات البحث.
2. لا قاعدة بيانات أو Supabase أو لوحة إدارة أو SPA في الإصدار الأول.
3. المحتوى يدار من ملفات JSON، مع معاينة محلية ثم نشر عبر GitHub وCloudflare Pages.
4. لا وعود بمواعيد إصدار غير مؤكدة ولا التزام بتعريب سلسلة كاملة.
5. صفحة المشروع الفردية هي أهم صفحة في التجربة.
6. الدقة التقنية، السرعة، ودقة المعلومات أهم من إضافة مزايا كثيرة.
7. العربية هي لغة الموقع الأساسية، مع دعم الأسماء والتسميات الإنجليزية تقنيًا وبشكل منضبط.
8. المحتوى الإباحي الصريح خارج نطاق الفريق؛ بعض الألعاب الناضجة غير الصريحة تقيم حالة بحالة مع تحذير محتوى.
9. لا تُنشئ مراجعات أو شهادات مستخدمين وهمية، ولا بيانات تنزيل أو مشروعات تجريبية مزيفة.

## الحالة الحالية باختصار

الموقع يعمل حاليًا بـ Astro، ويحتوي على صفحات ثابتة للمشاريع والمدونة والتصنيفات، وشعار سطح مكتب وعلامة هاتف، وتدقيق RTL/LTR، وsitemap وrobots. ما زال يحتاج تنفيذ نموذج المحتوى V2 في الملفات والصفحات، وإكمال SEO العملي مثل Open Graph موثوق وصفحة 404، ثم إعداد ربط GitHub وCloudflare Pages والنطاق قبل الإطلاق العام.

## المطلوب من المراجع الذكي

حلل الخطة والملفات وقدّم تطويرات عملية، لكن لا تعيد اقتراح بنية تناقض القيود أعلاه. ركز على:

1. اكتشاف التناقضات أو الثغرات بين الإجابات ونموذج البيانات وخطة التنفيذ.
2. تحسين ترتيب الأولويات قبل أول إصدار قابل للتحميل من Steins;Gate (الفصلان 0 و1).
3. اقتراح حقول JSON ناقصة فقط إذا كانت ضرورية فعلًا للتنزيل أو SEO أو سلامة المحتوى.
4. تحسين تجربة صفحة المشروع من الهاتف أولًا، خصوصًا التنزيل والتوافق والمشكلات المعروفة والتثبيت.
5. اقتراح اختبارات بناء تمنع الروابط المعطلة وبيانات الإصدار الناقصة قبل النشر.
6. مراجعة استراتيجية SEO العربية والإنجليزية من دون حشو كلمات مفتاحية أو استعمال أسماء فرق أخرى.
7. اقتراح ما يجب تأجيله بعد الإطلاق بدل تكديس مزايا مبكرة.

## شكل الإجابة المطلوب من الأداة

أعد الإجابة ضمن الأقسام التالية:

1. **ملخص فهم المشروع** في فقرة واحدة.
2. **قرارات يجب الحفاظ عليها**: قائمة قصيرة لا تتجاوز 10 نقاط.
3. **فجوات أو تناقضات مهمة**: مرتبة حسب الشدة مع سبب وحل مقترح.
4. **خطة محسنة من مراحل**: لكل مرحلة هدف، مخرجات، معيار قبول، ومخاطر.
5. **تحسينات نموذج JSON**: جداول أو أمثلة صغيرة فقط عند الضرورة.
6. **قائمة إطلاق أولى**: عناصر ضرورية، عناصر مؤجلة، وكيفية التحقق من كل عنصر.
7. **أسئلة توضيحية قليلة**: اسأل فقط عن قرارات لا يمكن استنتاجها من الملفات.

## قالب طلب جاهز للنسخ

> اقرأ الملفات المرفقة لمشروع Alpha Line، وهو موقع Static بـ Astro لفريق عربي لتعريب الألعاب. حلل خطة التطوير ونموذج المحتوى، ثم اقترح تحسينات تنفيذية لا تتعارض مع القيود غير القابلة للتفاوض في هذا الموجز. لا تقترح SPA أو قاعدة بيانات أو لوحة إدارة أو حلولًا تضعف SEO. ركز على أول إطلاق عام عند توفر إصدار Steins;Gate للفصلين 0 و1. استخدم شكل الإجابة المطلوب في نهاية هذا الملف، وميّز بوضوح بين القرارات المؤكدة والافتراضات والأسئلة المفتوحة.
