# المصادر التقنية

تم اختيار Astro لأن توثيقه الرسمي يؤكد أن الصفحات المبنية عبر المسارات المعتمدة على الملفات يمكن توليدها كملفات HTML ثابتة، وأن المسارات الديناميكية تُنشأ في وضع SSG باستخدام `getStaticPaths()`.

توضح وثائق Content Collections الرسمية أيضًا أن المحتوى المحلي بصيغ JSON وYAML وMarkdown مناسب للتحميل وقت البناء والتحقق من بنيته.

- https://docs.astro.build/en/guides/routing/
- https://docs.astro.build/en/guides/content-collections/
