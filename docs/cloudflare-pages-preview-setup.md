# إعداد معاينة Alpha Line على Cloudflare Pages

هذه المعاينة مرتبطة بعنوان ثابت هو `https://alpha-line-team.pages.dev`. لا يعني وجود العنوان أن الموقع جاهز للإطلاق؛ وضعه الحالي هو **preview**، لذلك يضع الموقع `noindex` ويمنع الزحف في `robots.txt` حتى يُبدَّل الوضع عمدًا عند الإطلاق.

## إعداد أول نشر من GitHub

بعد رفع مصدر المشروع إلى المستودع العام، يُنشأ مشروع **Pages** من المستودع نفسه. إعدادات البناء هي كما يلي:

| الإعداد | القيمة |
|---|---|
| إطار العمل | Astro أو لا شيء إن لم يظهر الاختيار |
| أمر البناء | `pnpm build` |
| مجلد النشر | `dist` |
| إصدار Node.js | 22 |
| فرع النشر | `main` |

في **Settings → Variables and Secrets** لمشروع Pages، تضاف قيمتا المعاينة الآتيتان مباشرة لكل من بيئة Production وPreview ما دام الموقع غير معلن:

```text
SITE_URL=https://alpha-line-team.pages.dev
ALPHA_LINE_SITE_MODE=preview
```

يبقى المستودع عامًا للمصدر فقط. لا تضاف إليه ملفات اللعبة أو الباتش أو رموز الدخول أو مفاتيح API أو ملفات غير مصرح بنشرها.

## عند شراء الدومين لاحقًا

لا تتغير روابط الصفحات أو ملفات المحتوى. بعد ربط النطاق في Pages وتأكيد عمله، يُستبدل فقط إعداد البيئة كما يلي:

```text
SITE_URL=https://alpha-line-team.ly
ALPHA_LINE_SITE_MODE=public
```

بعد ذلك يُعاد البناء، ويُفحص canonical وsitemap وrobots وOpen Graph على النطاق الجديد. لا يُحوَّل الوضع إلى `public` قبل وجود إصدار تعريب حقيقي، وقناة Telegram حقيقية، ومراجعة جميع الروابط الظاهرة.

## ملاحظة عن الأصول

R2 مؤجل حاليًا لأنه يتطلب وسيلة دفع في هذا الحساب. لذلك يجب إبقاء روابط الصور منظمة في `src/data/content.ts` حتى يمكن نقلها لاحقًا إلى R2 أو إلى أصل ثابت آخر من دون تعديل الصفحات والقوالب.
