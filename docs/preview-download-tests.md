# اختبار مصادر التنزيل في المعاينة

## الغرض

تعرض صفحة Steins;Gate نافذة **اختبار مصادر التنزيل** فقط في المعاينة. هذه نافذة لفحص تجربة المستخدم مع عدة مصادر خارجية، ولا تغيّر حالة المشروع ولا تضيف باتشًا أو إصدارًا عامًا.

## تشغيل الاختبار

عند تشغيل `pnpm dev` محليًا، تظهر المحطة تلقائيًا في صفحة:

```text
/translations/steins-gate/
```

في Cloudflare Pages التجريبي، اضبط متغير البيئة التالي فقط إن أردت أن تراها هناك:

```text
ALPHA_LINE_ENABLE_DOWNLOAD_TESTS=true
```

أما عند الإطلاق العام، استخدم:

```text
ALPHA_LINE_SITE_MODE=public
ALPHA_LINE_ENABLE_DOWNLOAD_TESTS=false
```

بهذا لا تصل بيانات التجربة وروابطها إلى الموقع العام حتى لو بقيت داخل سجل JSON.

## استبدال الاختبار بإصدار حقيقي

عند وجود أول باتش فعلي، احذف `previewTestDownloads` من JSON أو عطله، ثم استخدم `release` فقط بعد تعيين `release.published` إلى `true` وإدخال رقم إصدار حقيقي وتعليمات تثبيت وروابط تنزيل صالحة. يمنع التحقق الجمع بين إصدار منشور ونافذة اختبار مفعلة.
