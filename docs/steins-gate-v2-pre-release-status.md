# حالة Steins;Gate V2 قبل أول إصدار

**الحالة:** مطبّق محليًا ومهيأ للمعاينة الخاصة، وليس إعلانًا عن إصدار تعريب.

تم ترحيل سجل Steins;Gate إلى نموذج المحتوى V2 مع الإبقاء على المعلومات صادقة بالنسبة إلى مرحلة العمل الحالية. لا ينشئ الموقع الآن رقم إصدار، أو ملف تنزيل، أو رابط باتش، أو ادعاء توافق مُختبَر. بدلًا من ذلك، يعرض المشروع أنه **قيد العمل** ويعامل نسخة Steam مع CoZ Patch 2.2.0 وbuild 4138816 بوصفها هدف توافق يحتاج إلى اختبار عملي لاحق.

| المجال | الحالة الحالية | ما يضاف فقط عند توفره |
|---|---|---|
| حالة المشروع | قيد العمل من دون نسبة أو موعد | تُحدَّث وفق الحالة الفعلية فقط |
| مراحل التقدم | مراحل وصفية بلا وعود زمنية | انتقال المرحلة بعد إنجازها فعليًا |
| التوافق | هدف Steam / CoZ 2.2.0 / build 4138816، بانتظار التحقق | نتيجة اختبار مثبتة وإصدار اللعبة المتوافق |
| الإصدارات | لا يوجد إصدار منشور | رقم إصدار، تاريخ، نطاق تعريب، وملاحظات تغيير حقيقية |
| التنزيلات | مخفية بالكامل | مصادر تنزيل فعلية مرتبطة بإصدار منشور فقط |
| صفحة المشروع | تعرض حالة ما قبل الإصدار وتفاصيل المشروع | زر تنزيل وتعليمات تثبيت عند توفر ملف حقيقي |

## تحقق المحتوى

أضيف أمر تحقق للمحتوى ضمن المشروع:

```bash
pnpm validate:content
```

يتحقق الأمر من قيود البيانات قبل بناء Astro، ومنها أن التنزيلات لا تظهر بلا إصدار صالح، وأن الحقول المطلوبة في سجل V2 متماسكة. أصبح أمر البناء المعتاد يشغّل التحقق أولًا، لذلك يجب تنفيذ الآتي بعد كل تعديل على بيانات المشروع:

```bash
pnpm build
```

## عند أول إصدار فعلي

ينبغي إدخال معلومات الاختبار الحقيقية أولًا، ثم إضافة سجل إصدار واحد فقط يصف الفصول المتاحة ونطاق التعريب ونسخة اللعبة المختبرة. بعد ذلك يمكن إضافة مصدر تنزيل فعلي وتعليمات تثبيت، ثم تحويل صفحة المشروع إلى حالة إصدار منشور. لا ينبغي إضافة هذه البيانات مسبقًا كقالب أو مثال مرئي.
