# خيارات حفظ صور Alpha Line

> تاريخ التحقق: 21 أغسطس 2026. الأسعار والحدود تتغير، لذا تُراجع صفحة كل مزود قبل الاشتراك أو الترقية.

## Supabase Storage

بحسب صفحة تسعير Supabase الرسمية، تمنح الخطة المجانية 1 غيغابايت لتخزين الملفات، و5 غيغابايت من نقل البيانات الخارجة، ومشروعين نشطين بحد أقصى؛ وتُوقَف المشاريع المجانية بعد أسبوع من عدم النشاط. الخطة Pro تبدأ من 25 دولارًا شهريًا لكل منظمة، وتشمل 100 غيغابايت لتخزين الملفات و250 غيغابايت من نقل البيانات؛ ويُحتسب التخزين الزائد بمعدل 0.0213 دولار لكل غيغابايت شهريًا في المتوسط. [1] [2] [3]

هذا مناسب تقنيًا فقط إذا احتاج الموقع مستقبلًا إلى رفع ملفات من لوحة أو إلى قاعدة بيانات وصلاحيات. أما الموقع الحالي الثابت الذي تُضاف صوره يدويًا من JSON فلا يحتاج Supabase لمجرد حفظ أغلفة وصور قليلة.

## GitHub وGit LFS

GitHub مناسب لحفظ **الشفرة** والملفات النصية، وليس مكتبة الصور الأساسية. يسمح GitHub بالصور الصغيرة، لكنه يحذّر عند 50 ميبيبايت، ويحجب الملف العادي فوق 100 ميبيبايت، ويوصي أن يبقى المستودع أقل من 1 غيغابايت وألا يتجاوز 5 غيغابايت عمليًا. أما الملفات الكبيرة فتحتاج Git LFS، وحزمة LFS الإضافية المعروضة رسميًا هي 5 دولارات شهريًا مقابل 50 غيغابايت تخزين و50 غيغابايت نقل بيانات. [4] [5] [6]

لذلك لا تُوضع الأغلفة القليلة وصور الواجهة داخل المستودع إن كان الهدف إبقاء الشفرة نظيفة وسهلة النسخ؛ وتُحفظ فقط الملفات النصية الصغيرة أو أيقونات لا تحتاج تغييرًا متكررًا إن قررنا ذلك.

## Cloudflare R2 وCloudflare Images

لأن الاستضافة المخططة هي Cloudflare Pages، فإن **Cloudflare R2** هو الخيار المتوافق والأفضل لحفظ أغلفة الألعاب ولقطات التعريب في هذا المشروع. يمنح R2 مجانًا كل شهر 10 غيغابايت-شهر من التخزين، ومليون عملية كتابة، وعشرة ملايين عملية قراءة، ولا يفرض رسوم نقل بيانات خارجة. بعد المجاني تكون مساحة التخزين القياسية 0.015 دولار لكل غيغابايت-شهر، وعمليات القراءة 0.36 دولار لكل مليون طلب. [7]

لا نحتاج Cloudflare Images في البداية؛ فهو مفيد عندما نريد إعادة تحجيم تلقائية لنسخ الهاتف والبطاقات. خطته المجانية تشمل 5,000 تحويل صورة فريد شهريًا للأصول المحفوظة خارج خدمته، والخطة المدفوعة تسعّر التخزين بمقدار 5 دولارات لكل 100,000 صورة شهريًا والتسليم بدولار لكل 100,000 صورة. [8]

## التوصية الحالية

نختار R2 للنسخ المنشورة من الصور فقط، مع حفظ النسخ الأصلية الكبيرة محليًا وخارج المستودع. يُنشأ bucket عام واحد مثل `alpha-line-assets`، ويتفرع إلى `covers/` و`screenshots/` و`brand/` و`og/`. لا نضيف Supabase الآن: R2 يمنح مساحة مجانية أكبر بعشرة أضعاف، ويُبقي الصور قرب الاستضافة نفسها، ولا يستدعي قاعدة بيانات أو نظام حسابات.
