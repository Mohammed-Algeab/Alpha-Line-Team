# علامة Alpha Line: بوابة الأرشيف

## القرار المعتمد

تعتمد Alpha Line رمز **بوابة الأرشيف ذات المسارات الثلاثة** بدل حرف A. الرمز لا يعتمد على حرف أو إشارة إغريقية؛ بل يصور بوابة أو صفحة مفتوحة، ومحورًا عموديًا يقوده معين سماوي، وثلاثة مسارات في القاعدة. هذا يربط الاسم بـ«الخط» وبانتقال النص بين اللغات من دون لغة HUD أو شعار ألعاب تنافسي.

## نظام النسخ

| النسخة | الاستخدام | التكوين |
| --- | --- | --- |
| القفل الأفقي | رأس سطح المكتب وبطاقات التعريف | الرمز المتجه + ALPHA LINE + السطر الأرشيفي العربي |
| القفل المضغوط | رأس الهاتف | الرمز المتجه + ALPHA LINE؛ بلا معلومات ثانوية متزاحمة |
| الرمز وحده | favicon والواجهات الضيقة | البوابة، المعين السماوي، والمسارات الثلاثة فقط |
| صورة الحساب | Telegram وDiscord وTikTok وFacebook | PNG مربع 1024×1024 بخلفية Chronos ورمز كبير بلا نص |

## ألوان العلامة

| العنصر | اللون |
| --- | --- |
| أرضية الحساب | Chronos Charcoal `#0F1416` |
| جسم البوابة والمساران الخارجيان | Archive Ivory `#E8E2D6` |
| المعين والمسار الوسطي | Alpha Cyan `#5EC4E6` |
| خطا الإطار الجانبيان | Deep Cyan `#1C4E5B` |

لا يعاد إدخال حرف A داخل الرمز، ولا تستخدم النسخة العربية أو الإنجليزية التي قد تولدها أدوات الصور. الكتابة في الموقع نص حقيقي بخطوط الهوية حتى تبقى قابلة للقراءة ومتزنة في RTL وLTR.
