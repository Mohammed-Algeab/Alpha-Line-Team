# نموذج محتوى المدونة — الإصدار 2

> **الحالة:** مواصفة داخلية. تُطبّق بعد إتمام الاستبيان وتحديث قوالب Astro، ولا تغيّر ملفات المقالات الحالية تلقائيًا.

## الهدف

تكون مدونة Alpha Line مساحة تحريرية مرنة للألعاب والتعريب والأدوات والإعلانات، لا جدول نشر مفروض. ومع ذلك، تظل المقالات قابلة للعثور عليها عبر البحث والتصنيفات الاختيارية والتاريخ والروابط الداخلية إلى المشاريع ذات الصلة.

## نموذج مقال مقترح

```json
{
  "schemaVersion": 2,
  "slug": "steins-gate-localization-notes",
  "title": "ملاحظات أولية عن تعريب Steins;Gate",
  "excerpt": "ملخص قصير يظهر في بطاقة المقال وبيانات المشاركة.",
  "publishedAt": "2026-08-21",
  "author": "Alpha",
  "category": "تحديث مشروع",
  "cover": {
    "url": "https://images.example.com/article-cover.webp",
    "alt": "غلاف مقال عن Steins;Gate"
  },
  "relatedProjects": ["steins-gate"],
  "search": {
    "aliases": ["Steins Gate", "شتاينز غيت"],
    "indexable": true
  },
  "seo": {
    "title": "ملاحظات أولية عن تعريب Steins;Gate | Alpha Line",
    "description": "وصف مخصص اختياري لمحركات البحث."
  },
  "body": "نص المقال أو مسار ملف Markdown الخاص به."
}
```

## قواعد الحقول

| الحقل | إلزامي | القاعدة |
|---|---:|---|
| `title` و`excerpt` و`publishedAt` | نعم | تبني عنوان البطاقة والوصف والفرز الزمني. |
| `author` | نعم | اسم مستعار أو حقيقي، لكن يستعمل بالشكل نفسه لكل كاتب. |
| `category` | لا | تصنيف اختياري للفلترة؛ لا يمنع غيابه نشر المقال. |
| `cover` | لا | غلاف اختياري؛ إن غاب تستخدم البطاقة تدرج الهوية ولا تستخدم صورة بديلة مضللة. |
| `relatedProjects` | لا | قائمة `slug` لمشاريع موجودة؛ يتحقق البناء من صحتها وينشئ روابط داخلية تلقائيًا. |
| `search.aliases` | لا | صيغ عربية أو إنجليزية بديلة متصلة بالمقال، لتعمل في البحث الداخلي من دون حشو كلمات مفتاحية. |
| `search.indexable` | نعم | `true` للمقال المنشور و`false` للمسودة أو الصفحة غير المخصصة للظهور العام. |
| `seo` | لا | يسمح بضبط العنوان والوصف عند وجود سبب تحريري؛ وإلا تولد القيم من المقال. |

## قواعد العرض

تظهر بطاقات المقالات العنوان والملخص والتاريخ، وتضيف اسم الكاتب والتصنيف حين يتوفران. يعتمد أرشيف المدونة على البطاقات والبحث والفلترة؛ ولا ينشأ أرشيف شهري مستقل في النسخة الأولى. وعندما يحتوي المقال على `relatedProjects`، تعرض صفحته روابط مباشرة للمشاريع، وتستطيع صفحة المشروع أن تعرض أحدث المواد المرتبطة به.

لا يدخل المقال خريطة الموقع ولا قائمة البحث إن كانت `search.indexable` تساوي `false`. هذه القاعدة تغطي المسودات والمواد المؤقتة من غير الحاجة إلى مسارات خاصة أو حذف المحتوى من المستودع.

> **مبدأ تحريري:** لا توجد حاجة إلى مقال جديد إلا حين توجد مادة تستحق القراءة. البنية تخدم الاستمرارية عند توفرها، لكنها لا تفرض وتيرة نشر على الفريق.
