# المجتمع والتعليقات في Alpha Line

## القرار الحالي

لن يضاف نظام تعليقات عام إلى الموقع في مرحلة الإطلاق الأولى. سيُبنى المجتمع حول **Telegram** و**Discord** عندما تصبح قنواتهما جاهزة، مع مدخل واضح لهما في الرأس وصفحة التواصل.

هذا الموقع ثابت ويجب أن يبقى سريعًا وقابلًا للفهرسة ومركّزًا على ملفات التعريب. التعليقات ليست ضرورية للاعب لتنزيل باتش أو قراءة تعليمات التثبيت، بينما تحتاج إلى متابعة مستمرة ومكافحة إزعاج وحسابات وتبليغات.

## دور كل قناة

| القناة | الاستخدام الأساسي | ما لا تستخدم له |
| --- | --- | --- |
| Telegram | الإعلانات، سجل تحديثات قصير، روابط الإصدار | الدعم التقني الطويل أو البلاغات المفصلة |
| Discord | الدعم، قنوات الإبلاغ، أسئلة التثبيت، تنظيم المجتمع | جعل كل إعلان رسمي موزعًا في محادثات كثيرة |
| الموقع | النسخة المرجعية للمشروع، التنزيلات، سجل الإصدارات والتعليمات | نقاشات فورية أو تذاكر دعم |

## لماذا لا نستخدم Giscus الآن؟

Giscus يربط التعليقات بمناقشات GitHub. قد يكون مناسبًا لمدونة تقنية لها جمهور GitHub، لكنه يطلب تسجيل دخول GitHub من المتابعين، ويجعل النقاش العام مرتبطًا بمستودع المشروع، ولا يغني عن تنظيم الدعم لمستخدمين معظمهم لن يملكون حسابات GitHub. لذلك لا يلائم هدف Alpha Line الحالي.

## قاعدة التفعيل

لا يظهر زر المجتمع في الرأس إلا حين يوجد رابط Telegram أو Discord حقيقي ومفعّل في `src/content/site.json`. عند الإطلاق، اجعل Telegram قناة الإعلان الأساسية وDiscord مساحة الدعم المنظمة، ثم راجع الحاجة للتعليقات بعد وجود جمهور فعلي ونمط أسئلة متكرر.
