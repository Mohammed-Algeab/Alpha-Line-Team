# نموذج محتوى السلاسل — الإصدار 1

> **الحالة:** مواصفة داخلية تكمل نموذج المشاريع المقترح. لا تُفعّل قبل تطبيق المرحلة المقبلة من تحديث المحتوى.

## الهدف

السلسلة ليست مجرد وسم في بطاقة لعبة؛ إنها وجهة قابلة للتصفح والبحث تجمع كل المشاريع المتعلقة بها، أكانت من فريق Alpha Line أو تعريبات مستقلة. لذلك يحفظ كل ملف سلسلة بياناتها المشتركة مرة واحدة، بينما تشير إليها ملفات المشاريع عبر `slug`.

## نموذج ملف سلسلة

```json
{
  "slug": "science-adventure",
  "title": "SCIENCE ADVENTURE",
  "arabicTitle": "ساينس أدفنتشر",
  "shortLabel": "SciADV",
  "aliases": ["SciADV", "Science Adventure", "ساي أدف"],
  "description": "وصف عربي مختصر اختياري للسلسلة.",
  "cover": {
    "url": "https://images.example.com/science-adventure.webp",
    "alt": "غلاف سلسلة Science Adventure"
  },
  "indexable": true
}
```

## قواعد العرض

| المكان | ما يعرضه |
|---|---|
| صفحة السلسلة `/series/[slug]/` | تعريف اختياري للسلسلة، ثم جميع مشاريعها وفق الحالة والنوع. |
| فلاتر التعريبات | اسم السلسلة بالعربية والإنجليزية وفق المساحة المتاحة. |
| البحث | `title` و`arabicTitle` و`shortLabel` و`aliases`، مع أسماء الألعاب المرتبطة بها. |
| صفحة الخطط | المشاريع المخططة فقط؛ يمكن إضافة اسم السلسلة إليها للانتقال إلى صفحة السلسلة. |

لا تظهر السلسلة كصفحة مفهرسة إلا إذا كانت `indexable` تساوي `true` وتضم محتوى عامًا حقيقيًا؛ ذلك يمنع توليد صفحات فارغة أو تجميعات بلا قيمة للبحث.
