# نموذج محتوى مشاريع Alpha Line — الإصدار المقترح 2

> **الحالة:** مواصفة تطوير داخلية. لا تغيّر ملفات JSON الفعلية قبل اكتمال الاستبيان والموافقة على التطبيق.

## الهدف

يبقى الموقع **Static** ويقرأ مشروعًا واحدًا من ملف JSON واحد، لكنه يفصل بوضوح بين ثلاثة مستويات: بيانات اللعبة، حالة عمل فريق Alpha Line، والإصدارات القابلة للتنزيل. بهذه الطريقة يمكن تحديث مصدر تنزيل أو نطاق إصدار من دون إعادة كتابة وصف اللعبة أو خلط التقدم العام بالإصدار المنشور.

## مبادئ النموذج

| المبدأ | التطبيق في البيانات |
|---|---|
| لا وعود زمنية مصطنعة | تستخدم المشاريع مراحل وحالة عامة وملاحظة تحديث، لا تاريخ إطلاق إلزامي ولا نسبة مئوية إجبارية. |
| لا تنزيلات وهمية | لا يظهر زر التنزيل إلا حين يملك إصدارًا منشورًا رابطًا فعليًا واحدًا على الأقل. |
| قابل للإخفاء | تبقى قصة التعريب، وصف اللعبة الموسع، الانضمام، والمساهمون حقولًا اختيارية. |
| فصل المشروع عن الإصدار | يظهر المشروع في مرحلة الترجمة حتى عندما لا يوجد إصدار؛ وتظهر بيانات التوافق فقط داخل الإصدار. |
| إعداد من JSON فقط | لا قاعدة بيانات ولا لوحة تحكم؛ إضافة مشروع أو تحديثه تتم بتعديل الملف ثم بناء الموقع الثابت. |

## قيم ثابتة معتمدة

### حالات المشروع

| القيمة التقنية | النص العربي في الواجهة | الاستخدام |
|---|---|---|
| `in_progress` | جاري تنفيذ | توجد أعمال جارية، وقد لا يكون هناك إصدار منشور. |
| `completed` | مكتمل | وصل المشروع إلى إصدار تعريب مكتمل بحسب نطاقه المعلن. |
| `postponed` | مؤجل | توقف مؤقت مع نية محتملة للعودة. |
| `paused` | متوقف | لا توجد أعمال نشطة في الوقت الحالي. |
| `cancelled` | ملغي | أوقف المشروع نهائيًا. |
| `planned` | مخطط | مشروع معلن بقرار واعٍ قبل بدء التنفيذ؛ يظهر في صفحة الخطط ولا يعد بتنزيل أو موعد. |

### أنواع المشاريع

| القيمة التقنية | النص العربي | الاستخدام |
|---|---|---|
| `team` | مشروع الفريق | عمل معلن ضمن Alpha Line وإدارته ومسؤوليته تقعان على الفريق. |
| `independent` | تعريب مستقل | عمل مستقل يعرض في أرشيف مستقل، مع بقائه قابلًا للظهور داخل السلسلة التي ينتمي إليها. |

### حالات المراحل

| القيمة التقنية | النص العربي | مثال استعمال |
|---|---|---|
| `not_started` | لم تبدأ | مرحلة مراجعة لم يحِن وقتها. |
| `current` | جارية | مرحلة الترجمة النصية الآن. |
| `complete` | مكتملة | مرحلة تحليل الملفات انتهت. |
| `blocked` | معلّقة | مرحلة تتطلب أداة أو توافقًا غير متاح. |

## قواعد العرض والبناء

لا يطبع قالب المشروع «قصة التعريب» ما لم توجد قيمة غير فارغة لها. ويعرض رأس الصفحة `game.summary`، ثم يفتح الوصف الموسع عند توافر `game.story`. كما لا يولد زر التنزيل إن كانت `versions` فارغة أو لم يتوفر رابط صالح داخل أي `downloads`.

تظهر أول ثلاثة عناصر من التنزيلات التي تحمل `featured: true` كخيارات سريعة في قسم الإصدار، بحد أقصى ثلاثة. أما زر «تنزيل» فيفتح نافذة المصادر الكاملة مرتبة تصاعديًا حسب `order`. وفي حال تجاوزت التنزيلات المميزة الحد، يفشل فحص البناء برسالة واضحة بدل عرض أكثر من ثلاثة عناصر بالخطأ.

يمكن أن تختلف مراحل مشروع عن آخر، إلا أن البطاقة لا تحتاج لمعرفة أسماء المراحل. يكفيها حساب موضع `currentPhaseId` في `phases` وعرض الصيغة: «المرحلة الحالية: الترجمة — 3 من 6». لا تعرض البطاقة رقمًا مئويًا إلا إذا أضيفت تلك الميزة لاحقًا بقرار صريح.

### قواعد الإصدار والجودة

| الحقل | القيم أو القاعدة | أثره في الواجهة |
|---|---|---|
| `changelog` | قائمة موجزة بما يفهمه اللاعب | تظهر داخل سجل الإصدار بدل تفاصيل تقنية مرهقة. |
| `badges` | لا تستخدم في البداية إلا `fix` | تعرض «إصلاح» عند الحاجة؛ لا تعرض شارات تجريبية أو استقرار. |
| `knownIssues` | لا تضاف إلا مشكلة متحققة تؤثر على اللاعب | تظهر قبل زر التنزيل وضمن الإصدار المتأثر. |
| `availability` | `available` أو `removed` | لا يولد رابط تنزيل لإصدار `removed`. |
| `removedReason` | سبب داخلي أو نص عام اختياري | يستخدم عند إزالة إصدار يسبب مشكلة في اللعبة، ولا يترك رابطًا مكسورًا. |

لا تنشر النسخ التجريبية العامة في النسخة الأولى. ولا يحتاج النموذج إلى نظام إعلان آلي؛ فصفحة المشروع وسجل الإصدارات ينعكسان تلقائيًا في البناء الثابت، ثم يختار الفريق يدويًا مشاركة التحديثات المهمة في قنوات المجتمع بعد تجهيزها.

### قواعد الفهرسة والبحث

| الحقل | الاستخدام | القاعدة |
|---|---|---|
| `search.aliases` | يلتقط تهجئات الاسم العربية والإنجليزية من البحث الداخلي | يضم الاسم الرسمي والصيغ الشائعة فقط، من دون أسماء جهات أخرى أو كلمات غير مرتبطة بالمحتوى. |
| `search.seriesAliases` | يربط اللعبة باختصارات السلسلة وصيغ اسمها | يستخدم عند وجود سلسلة معروفة مثل `SciADV`. |
| `search.indexable` | يتحكم في ظهور صفحة المشروع ضمن البحث الثابت | تكون `true` للمشروع المكتمل أو الجاري فقط؛ وتكون `false` للمؤجل والمتوقف والملغي والمسودة. |
| `seo.title` و`seo.description` | تضبط نتيجة Google وبطاقات المشاركة عند وجود نص تحريري أفضل من المولد تلقائيًا | الحقلان اختياريان؛ يولدان تلقائيًا إن غابا. |
| `seo.socialImage` | بطاقة مشاركة المشروع | تستخدم صورة 1200×630 تجمع غلاف اللعبة وعلامة Alpha Line، لا غلافًا خامًا أو مسار HTML. |

تفهرس خريطة الموقع والـ`robots` الصفحة الرئيسية والمشاريع القابلة للفهرسة والمقالات المنشورة فقط. لا تظهر في الخريطة صفحات الانضمام والمسودات وسجلات داخلية وصفحات اختبار، حتى إن وُجدت في البناء لأغراض تشغيلية.

### قواعد السلسلة والخطط

كل مشروع يحمل `game.series.slug` يشير إلى ملف سلسلة مستقل في `src/content/series/`. لا يكرر المشروع اسم السلسلة ووصفها وصورتها؛ يحملها قالب المشروع من سجل السلسلة. وتعرض صفحة السلسلة جميع مشاريعها، من الفريق والمستقلة معًا، لأن الانتماء إلى السلسلة لا يتأثر بنوع المشروع.

تظهر المشاريع ذات `project.status: "planned"` في صفحة `/plans/` فقط، ولا تظهر في التنزيلات أو كجزء من المشاريع النشطة. ويجوز اختيار ظهورها في صفحة السلسلة عند الحاجة التحريرية، لكن تظل `search.indexable` مساوية لـ`false` حتى تتحول إلى `in_progress` أو `completed`، التزامًا بسياسة الفهرسة المعتمدة.

## الانتقال من النموذج الحالي

| الحقل الحالي | الوجهة المقترحة | ملاحظة الانتقال |
|---|---|---|
| `title` و`arabicTitle` | `titles.original` و`titles.arabic` | تغيير تنظيمي فقط. |
| `series` و`seriesLabel` | `game.series` | يحافظ على العرض العربي والإنجليزي. |
| `platforms` | `game.platforms` ثم `versions[].platforms` | الأولى للعبة، والثانية لكل ملف عند اختلاف التوافق. |
| `shortDescription` | `game.summary` | يظهر في الرأس والبطاقات. |
| `story` | `game.story` | اختياري. |
| `translationStory` | `project.translationStory` | اختياري ويخفي القسم إن غاب. |
| `status` و`statusKey` | `project.status` | يستبدل بالقيم التقنية المعتمدة. |
| `updatedAt` | `project.updatedAt` | صيغة ISO منضبطة في البيانات؛ تُنسق عربيًا في القالب. |
| `installation` | `versions[].install.steps` | تختلف التعليمات بحسب الإصدار. |
| `versions[]` الحالي | `versions[]` الموسع | يضاف التوافق والنطاق ومصادر متعددة وروابط فعلية. |
